## Resumo

Contratos mínimos de referência para formatos usados pelo `revisar-ppc`.

Os arquivos deste diretório não compõem o runtime da revisão. Eles documentam o formato esperado de fichas, batches e respostas de lote.

Os contratos verificáveis ficam em `../schemas/` e são conferidos por `node .agents/skills/revisar-ppc/scripts/revisar_ppc.ts validar-base` (também executado por `node scripts/validar_base.ts`).
